# Assets Directory

This directory contains the assets for the portfolio website:

- **profile.jpg**: Your profile photo (recommended size: 400x400px)
- **project1.jpg to project4.jpg**: Project screenshots (recommended size: 600x400px)
- **curriculo.pdf**: Your resume/CV in PDF format

## Instructions

Replace the placeholder text below with your actual image files and resume:

1. Add your profile photo as `profile.jpg`
2. Add project screenshots as `project1.jpg`, `project2.jpg`, `project3.jpg`, `project4.jpg`
3. Add your resume as `curriculo.pdf`

## Image Guidelines

- **Profile Photo**: Use a professional headshot with good lighting
- **Project Screenshots**: Use high-quality screenshots that showcase your work
- **File Formats**: JPEG for photos, PNG for screenshots with transparency
- **File Size**: Optimize images to keep file sizes under 500KB for better performance

## Placeholder Images

Until you add your own images, the site will use placeholder background gradients.
The orange gradient backgrounds will display where images are expected.
